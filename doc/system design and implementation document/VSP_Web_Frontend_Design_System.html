Section 1
Cross-Check: Web Frontend vs Backend
Every page and endpoint in the web spec checked against the 195-endpoint backend catalog. Gaps resolved below.
🟢 Endpoints Present in Backend — Web Pages Covered
✅
Auth, Search, Feed, Chat, Notifications, Bookings, Requests, Worker Profiles
All primary endpoints in the web spec exist in the backend. No changes needed for core flows.
🔴 Missing from Web Spec — Backend Has These, Frontend Didn't List Them
⚠️
Media Upload Flow — POST /api/v1/media/upload-url + POST /api/v1/media/confirm ADDED
Portfolio upload, certification upload, and avatar change all need signed URL flow. Frontend spec listed endpoints without the media upload flow. Both web and mobile must use: 1) POST /media/upload-url → 2) PUT signed URL → 3) POST /media/confirm.
⚠️
Review Submission — POST /api/v1/reviews missing from spec ADDED
Page 23 (Write Review) requires POST /api/v1/reviews. Listed in backend, missing from web spec endpoint list. Also: POST /api/v1/reviews/:reviewId/dimensions.
⚠️
Worker Assignment Accept/Decline missing from spec ADDED
Worker pages 42 (Request Detail/Respond) need POST /service-requests/:id/assignments/:id/accept and /decline. These exist in backend but were absent from mobile and web specs.
⚠️
Featured Subscription Purchase — Billing endpoints not in web spec ADDED
Worker Dashboard (page 40/45) shows earnings but worker can purchase featured subscription. Add: POST /api/v1/billing/payment-intents, GET /api/v1/billing/subscriptions/me, GET /api/v1/billing/invoices/me.
⚠️
Save/Unsave Worker — Customer flow incomplete ADDED
Page 16 (Saved Workers) requires POST + DELETE /api/v1/users/me/saved-workers/:workerId. Listed in backend but absent from web spec.
⚠️
Follow/Unfollow — Social feed requires follow system ADDED
Feed page requires POST + DELETE /api/v1/users/me/follows. Worker cards show Follow button. Not in web spec endpoints.
⚠️
Worker Availability (Pages 36) — endpoint missing from spec ADDED
Availability Management (page 36) needs POST/PATCH/DELETE /api/v1/worker-profiles/me/availability/rules and /exceptions.
⚠️
Booking Reschedule Response — page 22 incomplete ADDED
Booking Reschedule Flow (page 22) needs POST /api/v1/bookings/:id/reschedule/:rescheduleId/respond for the other party to accept/decline.
⚠️
Worker Analytics Summary (page 45) — no backend endpoint BACKEND GAP
The web spec has a Worker Analytics Summary page. The backend has no worker-facing analytics endpoint. SOLUTION: Add GET /api/v1/worker-profiles/me/analytics to the backend (returns jobs_completed, avg_rating, response_rate, review_count, monthly bookings chart data).
🆕 New Backend Endpoint Required — Worker Analytics
GET /api/v1/worker-profiles/me/analytics
Auth: Authenticated Worker
Response: {
  jobsCompleted: number,
  avgRating: number,
  totalReviews: number,
  responseRate: number,
  monthlyBookings: [{month, count, completed, cancelled}],
  ratingTrend: [{month, avgRating}],
  topTrades: [{tradeName, bookingCount}]
}

Section 6
Page Layout Patterns
Seven patterns cover all 45 pages. Each worker onboarding page uses Pattern 7.
1
Landing / Public Hero
Pages 1, 2, 5 — Landing, Explore Trades, Social Discovery
HeroSection (full-width gradient + headline + search bar + CTA)
FeaturedWorkers horizontal scroll cards
TradeGrid category icons grid
SocialProof stats + testimonials
Footer
2
Search Results — Sidebar + Grid
Pages 3, 13, 14 — Worker Search, Search Results, Map Search
SearchBar (top, full-width, filters inline)
Left sidebar 280px: FilterPanel (trade, radius, rating, price)
Right flex-1: WorkerGrid (3-col) or MapView toggle
Pagination or infinite scroll
3
Feed — Single Column Infinite Scroll
Pages 5, 11, 12 — Feed, Feed Detail
CreatePostBar (top — avatar + "Share an update...")
FeedList single column max-w-2xl centred
PostCard components — text | image | portfolio types
IntersectionObserver triggers next page fetch
SkeletonLoader while fetching next page
4
Profile / Detail — Full Width with Tabs
Pages 4, 15, 28, 29, 40, 41 — Worker Profile, User Profile, Worker Detail
ProfileHero (cover gradient + avatar + name + stats + CTA buttons)
ProfileTabs (About | Portfolio | Reviews | Services | Availability)
Tab content below — varies per tab
StickyContactCard right sidebar (book / message / save)
5
Inbox — Split Panel (Messages)
Pages 25, 26 — Messages Inbox, Conversation Detail
Left 320px: ConversationList — avatar + name + preview + unread count
Right flex-1: MessageThread — bubbles + timestamp
ChatInput sticky bottom: textarea + attach + send
Responsive: stack vertically below lg breakpoint
6
List + Detail — Bookings / Requests
Pages 18–21, 17–19 — Bookings, Requests
PageHeader + StatusTabs (All | Active | Completed | Cancelled)
BookingCard list — accent border by status
BookingDetail: hero + timeline + worker card + actions
Empty state: illustration + CTA to search workers
7
Multi-Step Onboarding Flow
Pages 31–39 — Worker Onboarding Steps
ProgressBar (Step X of 9 — linear steps top)
StepCard centered max-w-lg: title + description + form fields
StepFooter: Back + Continue / Skip buttons
ExitPrompt: "Progress saved — continue later"
