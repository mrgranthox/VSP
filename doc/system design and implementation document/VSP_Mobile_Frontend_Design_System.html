Section 1
Cross-Check: Mobile Frontend vs Backend
Mobile spec checked against 195-endpoint backend. Gaps found and resolved below.
Gaps Found — Resolved
⚠️
Media Upload — Signed URL flow missing from spec ADDED
Pages 32 (Portfolio Upload) and 33 (Certifications Upload) need: POST /media/upload-url → PUT signed URL → POST /media/confirm. Also avatar change needs this flow. Backend has it, spec didn't list it.
⚠️
Assignment Accept/Decline missing from mobile spec ADDED
Screen 37 (Request Response Screen) needs: POST /service-requests/:id/assignments/:id/accept and /decline. These exist in backend but were absent from mobile spec.
⚠️
POST /reviews missing from mobile spec ADDED
No review creation endpoint listed. Backend has POST /api/v1/reviews + POST /reviews/:id/dimensions. Required for booking completion flow.
⚠️
Worker Earnings (Screen 40) — No backend endpoint NEW ENDPOINT NEEDED
Screen 40 is "Worker Earnings / Performance Placeholder". Backend has no earnings endpoint. Add GET /api/v1/worker-profiles/me/analytics (same as web) showing jobs_completed, avg_rating, monthly bookings chart data. Mark as "Coming Soon" in UI until backend implements.
⚠️
Follow/Unfollow not in mobile spec ADDED
Feed cards show Follow button. POST + DELETE /api/v1/users/me/follows needed for feed and worker profile screens.
⚠️
Save Worker not in mobile spec ADDED
Screen 13 (Saved Workers) requires POST + DELETE /users/me/saved-workers/:workerId. Present in backend, absent from mobile spec.
⚠️
Availability Setup (Screen 31) — endpoints not listed ADDED
POST/PATCH/DELETE /worker-profiles/me/availability/rules and /exceptions required for Screen 31.
⚠️
Billing for Featured Subscription — not in mobile spec ADDED
Worker Performance screen should surface featured subscription upsell. Add: POST /billing/payment-intents + GET /billing/subscriptions/me to worker profile/dashboard flow.

Section 6
Mobile-Specific Implementation Rules
TOUCH TARGETS
Minimum 44×44pt touch area for all buttons and icons.
Add padding to small icons: hitSlop={{ top:8, bottom:8, left:8, right:8 }}

INFINITE SCROLL (FlatList)
const handleEndReached = () => { if (hasNextPage && !isFetching) fetchNextPage() }
onEndReachedThreshold={0.3} // load when 30% from bottom
keyExtractor={(item) => item.id}
ListFooterComponent={isFetchingNextPage ? <LoadingSpinner /> : null}

PULL TO REFRESH
refreshControl={<RefreshControl refreshing={isRefetching} onRefresh={refetch} />}

KEYBOARD AVOIDING
Wrap chat screens and forms in KeyboardAvoidingView behavior="padding"

MEDIA UPLOAD (Image Picker)
Use expo-image-picker. On select: POST /media/upload-url → PUT blob → POST /media/confirm
Show upload progress bar. Handle errors with retry.

PUSH NOTIFICATIONS
On first launch: request permission → POST /push-devices with FCM/APNs token
On logout: DELETE /push-devices/:deviceId

WEBSOCKET (Chat)
Connect on ConversationDetail screen mount. Disconnect on unmount.
Use reconnect with exponential backoff (max 30s).
Persist messages to AsyncStorage as fallback.
